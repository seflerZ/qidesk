Highlights

Built for serious remote work

Four pillars — multi-protocol coverage, a truly free open-source build, an external-display workflow, and input modes that feel natural on a phone.

All the protocols you need

RDP, VNC, Moonlight / NVStream and SSH in a single app. One connection list, one set of gestures, one tool for every machine on your desk.

Open source & zero data collection

Source on GitHub under a permissive license. The free build on GitHub Releases collects no telemetry, no analytics, no account — your phone talks directly to your machines, nothing in between.

External display · phone becomes a PC

Plug into a TV or monitor, pair a Bluetooth mouse and keyboard, and your phone is a real desktop. QxRemotes routes input from any HID device you attach.

Customisable gestures

Bind swipe, pinch, two-finger tap, and edge swipes to any remote action — scroll, zoom, switch input mode, invoke the keyboard, or fire a macro. One-handed, no menu digging.

Input

Three ways to control the remote

Each mode is a first-class citizen, not a buried toggle. Switch from the in-session toolbar.

Touchpad simulation

A two-finger trackpad on glass. One finger moves the cursor, two fingers scroll, tap-to-click, long-press for drag. Feels like a laptop trackpad the moment you pick up the phone.

Point-to-point touch

Direct mapping — wherever your finger lands on the screen is exactly where it lands on the remote. Best for drawing, drawing tools, and any UI where absolute coordinates matter.

Gamepad mapping

On-screen controller with remappable buttons and stick zones. Perfect for Moonlight game streaming and any remote app that wants a console-style input device.
